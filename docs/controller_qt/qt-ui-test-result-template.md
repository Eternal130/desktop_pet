# controller_qt UI 测试结果报告

> **文档性质**:测试结果记录模板。
> **配套测试用例**:[`qt-ui-manual-test.md`](./qt-ui-manual-test.md)(74 个用例,Phase 4–9 + 跨页)。
>
> ## 使用说明
>
> 1. **复制本文件**:重命名为 `qt-ui-test-result-YYYYMMDD.md`(例如 `qt-ui-test-result-20260721.md`)。
> 2. **执行测试**:按 `qt-ui-manual-test.md` 中各 TC 的"前置 / 步骤 / 预期"逐项操作。
> 3. **填写结果**:在第三章每行勾选结果(把 `☐` 改为 `☑`),并补齐耗时与备注。
> 4. **失败/跳过**:在第四、五章填写结构化详情。
> 5. **不要删模板**:`qt-ui-test-result-template.md` 永远是空白模板,每次新一轮测试都从这里复制。
>
> **结果代码**:`PASS` = 全部预期项出现;`FAIL` = 至少一项未出现或出现未预期行为;`N/A` = 平台/环境不支持(必须填跳过原因);`BLK` = 阻塞,无法执行(例如前置依赖失败)。
