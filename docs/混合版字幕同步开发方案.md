# 混合版字幕同步系统开发方案

> 结合 lipSync 时间戳和字幕文本的智能同步方案
> 目标：实现精确的字幕显示，与音频和嘴型完美对齐

---

## 1. 项目概述

### 1.1 目标
- 仅凭语音包实现字幕显示
- 字幕吐字间隔与音频精确对齐
- 字幕节奏与嘴型变化同步

### 1.2 核心技术
- **lipSync 时间戳**：提供精确的时间序列（0.00s, 0.03s, ...）
- **字幕文本**：从 `VoicePackAction.doc` 获取
- **智能分配算法**：根据时间戳比例、停顿（X）、词边界动态分配字符

### 1.3 项目现状
✅ 已有：
- `VoicePackScanner`：语音包扫描器
- `MetaMkoParser`：meta.mko 解析器
- `VoicePackAction`：包含 `audioPath`、`lipSyncPath`、`doc` 字段
- 现有的 lipSync 文件格式：`时间戳 \t 嘴型标识`

❌ 缺失：
- 音频播放器
- 字幕显示系统
- 时间戳同步调度器
- 字幕生成器

## 3. 核心模块设计

### 3.1 数据模型

```java
package com.desktoppet.subtitle;

// lipSync 帧数据
public record LipSyncFrame(double timestamp, String phoneme) {
    public static LipSyncFrame fromLine(String line) {
        String[] parts = line.split("\t");
        double time = Double.parseDouble(parts[0].trim());
        String phoneme = parts[1].trim();
        return new LipSyncFrame(time, phoneme);
    }
}

// 字幕段（带时间戳）
public record SubtitleSegment(double startTime, String text) {}

// 字幕播放任务
public record SubtitleTask(
    String audioPath,
    String subtitleText,
    List<SubtitleSegment> segments
) {}
```

### 3.2 LipSyncParser

**职责**：解析 lipSync 文件，提取时间戳序列

```java
public final class LipSyncParser {

    public static List<LipSyncFrame> parse(Path lipSyncPath) throws IOException {
        List<LipSyncFrame> frames = new ArrayList<>();
        List<String> lines = Files.readAllLines(lipSyncPath);

        for (String line : lines) {
            if (line.trim().isEmpty() || line.startsWith("#")) {
                continue;
            }
            frames.add(LipSyncFrame.fromLine(line));
        }

        return frames;
    }
}
```

### 3.3 SubtitleGenerator

**职责**：根据 lipSync 时间戳生成字幕时间轴

**提供三种生成策略**：

#### 3.3.1 基础版：按时间比例分配
```java
public static List<SubtitleSegment> createBasicSegments(
        List<LipSyncFrame> frames,
        String subtitleText
) {
    double totalDuration = frames.getLast().timestamp;
    int totalChars = subtitleText.length();
    List<SubtitleSegment> segments = new ArrayList<>();
    int charIndex = 0;

    for (int i = 0; i < frames.size() - 1; i++) {
        double startTime = frames.get(i).timestamp;
        double endTime = frames.get(i + 1).timestamp;
        double segmentDuration = endTime - startTime;

        int segmentSize = Math.max(
            1,
            (int) Math.round(segmentDuration / totalDuration * totalChars)
        );

        if (charIndex >= totalChars) break;

        int endIndex = Math.min(charIndex + segmentSize, totalChars);
        segments.add(new SubtitleSegment(
            startTime,
            subtitleText.substring(charIndex, endIndex)
        ));
        charIndex = endIndex;
    }

    return segments;
}
```

#### 3.3.2 智能版：考虑停顿（X）
```java
public static List<SubtitleSegment> createSmartSegments(
        List<LipSyncFrame> frames,
        String subtitleText
) {
    double totalDuration = frames.getLast().timestamp;
    int totalChars = subtitleText.length();
    List<SubtitleSegment> segments = new ArrayList<>();
    int charIndex = 0;

    for (int i = 0; i < frames.size() - 1; i++) {
        double startTime = frames.get(i).timestamp;
        double endTime = frames.get(i + 1).timestamp;
        double segmentDuration = endTime - startTime;

        // X 表示停顿，此时可以多显示一些字符
        boolean isPause = "X".equals(frames.get(i).phoneme());
        int baseSize = (int) Math.round(segmentDuration / totalDuration * totalChars);

        int segmentSize = isPause
            ? Math.max(2, baseSize * 2)
            : Math.max(1, baseSize);

        if (charIndex >= totalChars) break;

        int endIndex = Math.min(charIndex + segmentSize, totalChars);
        segments.add(new SubtitleSegment(
            startTime,
            subtitleText.substring(charIndex, endIndex)
        ));
        charIndex = endIndex;
    }

    return segments;
}
```

#### 3.3.3 词边界版：优先在词边界切分
```java
public static List<SubtitleSegment> createWordAwareSegments(
        List<LipSyncFrame> frames,
        String subtitleText
) {
    List<SubtitleSegment> segments = new ArrayList<>();
    double totalDuration = frames.getLast().timestamp;
    int totalChars = subtitleText.length();

    int charIndex = 0;
    for (int i = 0; i < frames.size() - 1; i++) {
        double startTime = frames.get(i).timestamp;
        int targetIndex = (int) Math.round(
            (i + 1) * totalChars / (frames.size() - 1.0)
        );

        int wordBoundary = findWordBoundary(subtitleText, charIndex, targetIndex);
        int endIndex = Math.min(wordBoundary, totalChars);

        segments.add(new SubtitleSegment(
            startTime,
            subtitleText.substring(charIndex, endIndex)
        ));
        charIndex = endIndex;

        if (charIndex >= totalChars) break;
    }

    return segments;
}

private static int findWordBoundary(String text, int start, int target) {
    for (int i = target; i > start; i--) {
        char c = text.charAt(i);
        if (Character.isWhitespace(c) || isPunctuation(c)) {
            return i + 1;
        }
    }
    return target;
}
```

### 3.4 SubtitleScheduler

**职责**：根据字幕时间轴，在指定时间触发显示

```java
public final class SubtitleScheduler {

    private final ScheduledExecutorService scheduler;
    private final Consumer<String> onSubtitleDisplay;

    public SubtitleScheduler(Consumer<String> onSubtitleDisplay) {
        this.scheduler = Executors.newSingleThreadScheduledExecutor();
        this.onSubtitleDisplay = onSubtitleDisplay;
    }

    public void scheduleSubtitles(List<SubtitleSegment> segments) {
        for (SubtitleSegment segment : segments) {
            long delayMs = (long) (segment.startTime() * 1000);
            scheduler.schedule(() -> {
                onSubtitleDisplay.accept(segment.text());
            }, delayMs, TimeUnit.MILLISECONDS);
        }
    }

    public void cancelAll() {
        scheduler.shutdownNow();
    }
}
```

### 3.5 SubtitleService

**职责**：协调字幕播放的完整流程

```java
@Service
public final class SubtitleService {

    private final LipSyncParser lipSyncParser;
    private final SubtitleGenerator subtitleGenerator;
    private final SubtitleScheduler subtitleScheduler;
    private final AudioPlayer audioPlayer;

    public void playWithSubtitle(VoicePackAction action) {
        String audioPath = action.audioPath();
        String lipSyncPath = action.lipSyncPath();
        String subtitleText = action.doc();

        Path voicePackDir = getVoicePackDir(action);
        Path fullLipSyncPath = voicePackDir.resolve(lipSyncPath);
        Path fullAudioPath = voicePackDir.resolve(audioPath);

        try {
            List<LipSyncFrame> frames = lipSyncParser.parse(fullLipSyncPath);
            List<SubtitleSegment> segments = subtitleGenerator.createSmartSegments(
                frames,
                subtitleText
            );

            subtitleScheduler.scheduleSubtitles(segments);
            audioPlayer.play(fullAudioPath);

        } catch (IOException e) {
            log.error("Failed to play subtitle", e);
        }
    }
}
```

## 7. 风险与挑战

### 7.1 技术风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 时间戳精度不足 | 字幕不同步 | 使用 `System.nanoTime()` 替代 `System.currentTimeMillis()` |
| 音频与字幕延迟 | 用户体验差 | 添加手动偏移调整选项 |
| lipSync 文件格式变化 | 解析失败 | 添加版本检测和兼容性处理 |

### 7.2 性能挑战

| 挑战 | 解决方案 |
|------|----------|
| 大量字幕段影响性能 | 使用对象池、缓存机制 |
| 实时调度 CPU 占用高 | 优化调度算法，批量处理 |
| 内存占用 | 限制同时播放的字幕数量 |
