交互逻辑：上传 = 「上传图片」按钮或虚线卡 → FileDialog(多选) / 拖放；导入管线 = QImage 校验解码 → 转 PNG → sha256 命名 → 落盘 assets/uploads/ → 元数据 INSERT app.db（哈希重复时静默跳过并提示"已存在"）。预览 = FluContentDialog 放大图 + 完整元数据（原始文件名 / 哈希 / 尺寸 / 大小 / 上传时间 / 引用列表）。删除 = 二次确认对话框；被引用中的图片（当前 logo / 任一实例图标）删除时对话框列出受影响引用并要求先解除引用（引导跳转 Logo 页 / 实例详情页），未使用图片直接删文件 + db 记录。 删除实例不删图片——实例仅持有 asset_id 引用（与 emoji 图标同语义），引用随实例删除自动解除。
⑦ Logo 替换（并入设置 · 外观分区 — 不占一级导航）
位置决策：Logo 替换是低频一次性个性化操作，不单独占导航项（导航留给实例/监控/语音包/资源等高频页面）， 收进「设置 → 外观」分区。布局 = 设置页左锚点导航 + 右侧设置卡片的既有模式：预览卡 + 来源选择卡 + 上传卡。 选择即预览、应用后持久化到 app.db（panel_config），删图片不回退默认——logo 同样是引用，被删除需先在资源管理页解除。
