# 扩展性预留

> 系统设计概述参见 [系统设计](./README.md)，整体架构参见 [架构总览](../README.md)。

---

## 一、插件/脚本系统

未来计划支持 **Lua 脚本** 扩展宠物行为。当前版本仅做架构预留：

- 交互处理器（InteractionHandler）设计为可插拔接口，未来可由 Lua 脚本实现自定义响应逻辑
- 闲时行为的权重打分机制预留脚本注入点，允许插件注册新动作和权重函数
- 模型行为映射配置（model_config.json）的结构可扩展，未来支持脚本字段

本版本不实现 Lua 运行时和插件加载器。

---

## 二、状态系统

状态管理器（PetStateManager）预留养成属性接口，未来可引入心情、活力、好感度等属性，驱动行为决策从随机选择升级为权重打分。
