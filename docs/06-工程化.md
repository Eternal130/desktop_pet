## 一、构建与分发

### 1.1 目标平台

| 阶段 | 平台 | 窗口系统 |
|:---|:---|:---|
| MVP | Ubuntu 桌面版 | X11 |
| 后期 | Windows | Win32/DWM |

### 1.2 构建方案

- **C++ 渲染引擎**：CMake 构建，编译为平台原生可执行文件
- **Java 控制面板**：Maven 构建，使用 jlink/jpackage 打包最小化 JRE（用户无需自行安装 Java）

### 1.3 分发形式

同时提供两种分发形式：

| 形式 | Ubuntu | Windows（后期） |
|:---|:---|:---|
| 安装包 | .deb | .msi / .exe |
| 免安装压缩包 | .tar.gz | .zip |

### 1.4 打包结构

```plain
desktop-pet/
├── bin/
│   ├── desktop-pet-controller    # Java 控制面板（含内嵌 JRE）
│   └── desktop-pet-renderer      # C++ 渲染引擎可执行文件
├── lib/
│   ├── *.so / *.dll              # 运行时动态库
│   └── runtime/                  # 内嵌 JRE
├── models/                       # 默认模型
│   └── default/
└── config/
    └── config.json               # 默认配置（首次启动复制到用户目录）
```

## 三、第三方库选型

### 3.1 C++ 端

| 库                   | 用途             |
| :------------------ | :------------- |
| Cubism Native SDK   | Live2D 模型加载和渲染 |
| GLFW                | 窗口管理和输入处理      |
| GLEW                | OpenGL 扩展加载    |
| IXWebSocket         | WebSocket 服务端  |
| nlohmann/json       | JSON 解析        |
| OpenAL / SDL\_mixer | 音频播放（二选一）      |

### 3.2 Java 端

| 库              | 用途            |
| :------------- | :------------ |
| Java-WebSocket | WebSocket 客户端 |
| Gson           | JSON 处理       |
| JavaFX 或 Swing | UI 框架         |
