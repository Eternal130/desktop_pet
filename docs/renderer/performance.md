# 性能设计

> 渲染引擎模块概览参见 [渲染引擎设计](./README.md)，整体架构参见 [架构总览](../README.md)。

---

## 一、自适应帧率

渲染引擎根据当前状态动态调整帧率，降低资源占用：

| 状态 | 目标帧率 | 说明 |
|:---|:---|:---|
| 动画播放中 | 60fps | 确保动画流畅 |
| 闲时（呼吸/微动） | 30fps | 维持基本动态效果 |
| 完全静止 | 15fps | 仅维持渲染循环 |
| 窗口被遮挡/最小化 | 暂停渲染 | 不消耗 GPU 资源 |

---

## 二、设计原则

- 桌面宠物为常驻后台进程，闲时资源占用应尽量低
- 不设硬性内存/CPU 上限，但设计上避免资源泄漏（纹理及时释放、音频缓存有上限 LRU 策略）
- 渲染引擎主循环使用 `glfwWaitEventsTimeout(1.0/30.0)` 而非 `glfwPollEvents`，闲时降低 CPU 轮询频率
- WebSocket 消息通过 `glfwPostEmptyEvent()` 唤醒主循环，确保指令及时处理而不增加闲时开销
