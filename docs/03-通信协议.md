# 通信协议

> 本文档定义控制面板与渲染引擎之间的 WebSocket 通信协议。
> 整体架构参见 [架构总览](./00-架构总览.md)，实现库选型参见 [工程化](./06-工程化.md)。
>
> 实现端：C++ 端使用 IXWebSocket（Server），Java 端使用 Java-WebSocket（Client），JSON 序列化分别使用 nlohmann/json 和 Gson。

---

## 一、消息 Envelope 格式

所有 WebSocket 消息均使用统一的 JSON Envelope 格式：

```json
{
  "type": "command | event | response",
  "action": "play_motion",
  "id": "msg-uuid-001",
  "payload": { },
  "timestamp": 1710000000000
}
```

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| `type` | string | 消息类型：`command`（控制面板→渲染器）、`event`（渲染器→控制面板）、`response`（对 command 的回执） |
| `action` | string | 具体操作名称 |
| `id` | string | 消息唯一 ID（UUID），用于关键指令的 request-response 匹配 |
| `payload` | object | 消息负载数据 |
| `timestamp` | number | 发送时间戳（毫秒） |

**Response 格式**（仅关键指令需要回执）：

```json
{
  "type": "response",
  "action": "load_model",
  "id": "msg-uuid-001",
  "payload": {
    "success": true,
    "error_code": null,
    "error_message": null
  },
  "timestamp": 1710000000100
}
```

## 二、控制面板 → 渲染器（Commands）

| action | payload | 需要回执 | 说明 |
|:---|:---|:---|:---|
| `hello` | `{ version, client_name }` | 否（等待 `ready` 事件） | 握手 |
| `load_model` | `{ model_path, position? }` | **是** | 加载模型（已有模型时自动替换） |
| `play_motion` | `{ group, index, priority }` | 否 | 播放动作 |
| `stop_motion` | `{}` | 否 | 停止当前动作 |
| `set_expression` | `{ expression_id }` | 否 | 设置表情 |
| `set_position` | `{ x, y }` | 否 | 设置窗口位置 |
| `set_scale` | `{ scale }` | 否 | 设置模型缩放 |
| `set_volume` | `{ volume: 0.0-1.0 }` | 否 | 设置音量 |
| `set_mute` | `{ muted: bool }` | 否 | 静音 |
| `play_audio` | `{ audio_path }` | 否 | 播放独立音频 |
| `stop_audio` | `{}` | 否 | 停止音频 |
| `set_opacity` | `{ opacity: 0.0-1.0 }` | 否 | 窗口透明度 |
| `shutdown` | `{}` | **是** | 优雅关闭渲染器 |

## 三、渲染器 → 控制面板（Events）

| action | payload | 说明 |
|:---|:---|:---|
| `ready` | `{ version, capabilities }` | 握手回复，渲染器就绪 |
| `model_loaded` | `{ model_id, motions[], expressions[] }` | 模型加载完成，附带可用动作/表情列表 |
| `model_load_failed` | `{ error_code, error_message }` | 模型加载失败 |
| `motion_started` | `{ group, index }` | 动作开始播放 |
| `motion_finished` | `{ group, index }` | 动作播放结束 |
| `hit` | `{ area_id, x, y, button }` | 点击命中 |
| `drag_start` | `{ x, y }` | 拖拽开始 |
| `drag_end` | `{ x, y }` | 拖拽结束 |
| `audio_started` | `{ audio_path }` | 音频开始播放 |
| `audio_ended` | `{ audio_path }` | 音频播放结束 |
| `error` | `{ error_code, error_message }` | 错误上报 |
