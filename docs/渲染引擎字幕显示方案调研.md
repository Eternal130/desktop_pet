## 2. 字幕渲染技术选型

### 2.1 文本渲染库对比

| 库名 | 优势 | 劣势 | 推荐度 |
|--------|--------|--------|---------|
| **freetype-gl** | ✅ 支持完整Unicode（中文、日文）<br>✅ 单纹理+单VBO<br>✅ 成熟稳定<br>✅ 支持多种字体格式 | ⚠️ 依赖FreeType<br>⚠️ 需要额外编译 | ⭐⭐⭐⭐⭐ |
| **freetype-gl-cpp** | ✅ C++封装，易用<br>✅ 面向对象<br>✅ 性能优化 | ⚠️ 需要同时编译两个库<br>⚠️ API相对简化 | ⭐⭐⭐⭐ |
| **mrandri19/freetype-opengl-experiments** | ✅ 子像素抗锯齿<br>✅ 支持ligatures<br>✅ 支持emoji<br>✅ 高性能 | ⚠️ 较复杂<br>⚠️ 文档较少 | ⭐⭐⭐ |
| **stb_truetype** | ✅ 单头文件<br>✅ 零依赖<br>✅ 易集成 | ❌ 不支持hinting<br>❌ 不支持ligatures<br>❌ 需要自己实现复杂特性 | ⭐⭐ |

### 2.2 推荐方案：freetype-gl

**选择理由**：
1. **完整Unicode支持**：原生支持中文、日文、英文
2. **性能优秀**：单纹理+单VBO，批量渲染
3. **成熟稳定**：被众多项目使用，社区活跃
4. **易于集成**：C/C++项目，与现有技术栈匹配

**核心特性**：
- 纹理图集（Texture Atlas）：将所有字符打包到一张纹理
- 顶点缓冲：单个VBO渲染所有字符
- 自定义字体：支持.ttf/.otf格式
- 文本样式：颜色、大小、对齐方式

## 3. 字幕风格实现方案

### 3.1 字幕风格清单

| 风格 | 实现方式 | 技术难度 | 视觉效果 |
|--------|----------|----------|----------|
| **基础文本** | 直接渲染 | 简单 | 纯色文字 |
| **描边** | 多次渲染或shader混合 | 中等 | 文字轮廓，增强可读性 |
| **阴影** | 偏移渲染或shader | 简单 | 文字下方阴影，立体感 |
| **渐变** | Fragment shader | 中等 | 文字颜色渐变 |
| **发光** | Blur shader + 叠加 | 困难 | 文字发光效果 |
| **背景** | 背景矩形 | 简单 | 半透明背景，增强对比 |

### 3.2 描边实现方案

**方案A：多次渲染（CPU）**
```cpp
// 渲染8次，每个方向偏移1像素
for (int i = 0; i < 8; i++) {
    float offsetX = (i % 3 - 1) * outlineWidth;
    float offsetY = (i / 3 - 1) * outlineWidth;
    RenderText(text, x + offsetX, y + offsetY, outlineColor);
}
// 渲染本体
RenderText(text, x, y, textColor);
```

**优点**：实现简单，不依赖复杂shader
**缺点**：性能较差（渲染次数 = 风格数量 + 1）

**方案B：Shader混合（GPU）推荐**
```glsl
// Fragment Shader
uniform vec4 uTextColor;
uniform vec4 uOutlineColor;
uniform sampler2D uTextTexture;
uniform float uOutlineWidth;
uniform vec2 uTextureSize;

void main() {
    vec2 texCoord = vTexCoord;
    vec2 offset = vec2(uOutlineWidth) / uTextureSize;

    // 采样8个方向的像素
    vec4 outlineColor = vec4(0.0);
    outlineColor = max(outlineColor, texture(uTextTexture, texCoord + vec2( offset.x,  offset.y)));
    outlineColor = max(outlineColor, texture(uTextTexture, texCoord + vec2( offset.x, -offset.y)));
    outlineColor = max(outlineColor, texture(uTextTexture, texCoord + vec2(-offset.x,  offset.y)));
    outlineColor = max(outlineColor, texture(uTextTexture, texCoord + vec2(-offset.x, -offset.y)));

    // 混合：描边 + 文本
    vec4 texColor = texture(uTextTexture, texCoord);
    vec4 finalColor = mix(uOutlineColor, uTextColor, texColor.a);
    finalColor.a = max(finalColor.a, outlineColor.a);

    gl_FragColor = finalColor;
}
```

**优点**：一次渲染，性能优秀
**缺点**：需要编写shader

### 3.3 阴影实现方案

```cpp
// 渲染阴影：偏移 + 半透明
RenderText(text, x + shadowOffsetX, y + shadowOffsetY,
         shadowColor * vec4(1.0, 1.0, 1.0, 0.5));
// 渲染本体
RenderText(text, x, y, textColor);
```

### 3.4 渐变实现方案

```glsl
// Fragment Shader
uniform vec4 uGradientStart;
uniform vec4 uGradientEnd;
uniform vec2 uTextPosition;

void main() {
    vec4 texColor = texture(uTextTexture, vTexCoord);
    if (texColor.a < 0.1) discard;

    // 计算渐变
    float gradientPos = (vPosition.y - uTextPosition.y) / textHeight;
    vec4 gradientColor = mix(uGradientStart, uGradientEnd, gradientPos);

    vec4 finalColor = gradientColor * texColor.a;
    gl_FragColor = finalColor;
}
```

### 5.2 命令处理器实现

```cpp
// CommandHandlers.cpp 新增
void RegisterCommandHandlers(MessageHandler& handler, LAppDelegate* delegate) {
    // ... 现有命令 ...

    // 新增：显示字幕
    handler.registerCommand("show_subtitle", [delegate](const Envelope& cmd, auto sendResponse) {
        std::string text = cmd.payload.value("text", "");
        std::string style = cmd.payload.value("style", "BASIC");
        float posX = cmd.payload.value("x", 0.5f);
        float posY = cmd.payload.value("y", 0.8f);
        long duration = cmd.payload.value("duration", 0L);

        if (text.empty()) {
            sendResponse(createResponse(cmd.id, "show_subtitle", false, 9001, "text is required"));
            return;
        }

        SubtitleRenderer* subtitleRenderer = delegate->GetSubtitleRenderer();
        if (!subtitleRenderer) {
            sendResponse(createResponse(cmd.id, "show_subtitle", false, 9002, "Subtitle renderer not initialized"));
            return;
        }

        // 应用样式
        ApplyStyle(subtitleRenderer, style, cmd.payload["style_config"]);

        // 设置文本和位置
        int screenW = delegate->GetWindowWidth();
        int screenH = delegate->GetWindowHeight();
        subtitleRenderer->SetPosition(posX * screenW, posY * screenH);
        subtitleRenderer->SetText(text);
        subtitleRenderer->SetVisible(true);

        // 自动隐藏
        if (duration > 0) {
            std::thread([subtitleRenderer, duration]() {
                std::this_thread::sleep_for(std::chrono::milliseconds(duration));
                subtitleRenderer->SetVisible(false);
            }).detach();
        }

        sendResponse(createResponse(cmd.id, "show_subtitle", true));
    });

    // 新增：隐藏字幕
    handler.registerCommand("hide_subtitle", [delegate](const Envelope& cmd, auto sendResponse) {
        SubtitleRenderer* subtitleRenderer = delegate->GetSubtitleRenderer();
        if (subtitleRenderer) {
            subtitleRenderer->SetVisible(false);
        }
        sendResponse(createResponse(cmd.id, "hide_subtitle", true));
    });

    // 新增：更新字幕
    handler.registerCommand("update_subtitle", [delegate](const Envelope& cmd, auto sendResponse) {
        std::string text = cmd.payload.value("text", "");

        SubtitleRenderer* subtitleRenderer = delegate->GetSubtitleRenderer();
        if (subtitleRenderer && !text.empty()) {
            subtitleRenderer->SetText(text);
        }

        sendResponse(createResponse(cmd.id, "update_subtitle", true));
    });
}

void ApplyStyle(SubtitleRenderer* renderer, const std::string& style, const nlohmann::json& config) {
    SubtitleStyleConfig styleConfig;

    if (style == "BASIC") {
        // 基础样式
    } else if (style == "OUTLINE") {
        styleConfig.fontSize = config.value("font_size", 24.0f);
        styleConfig.textColor = ParseColor(config["text_color"]);
        styleConfig.outlineColor = ParseColor(config["outline_color"]);
        styleConfig.outlineWidth = config.value("outline_width", 2.0f);
    } else if (style == "SHADOW") {
        styleConfig.fontSize = config.value("font_size", 24.0f);
        styleConfig.textColor = ParseColor(config["text_color"]);
        styleConfig.shadowColor = ParseColor(config["shadow_color"]);
        styleConfig.shadowOffset = ParseVec2(config["shadow_offset"]);
    } else if (style == "OUTLINE_SHADOW") {
        // 描边+阴影
        styleConfig.fontSize = config.value("font_size", 24.0f);
        styleConfig.textColor = ParseColor(config["text_color"]);
        styleConfig.outlineColor = ParseColor(config["outline_color"]);
        styleConfig.outlineWidth = config.value("outline_width", 2.0f);
        styleConfig.shadowColor = ParseColor(config["shadow_color"]);
        styleConfig.shadowOffset = ParseVec2(config["shadow_offset"]);
    } else if (style == "GRADIENT") {
        styleConfig.fontSize = config.value("font_size", 24.0f);
        styleConfig.gradientStart = ParseColor(config["gradient_start"]);
        styleConfig.gradientEnd = ParseColor(config["gradient_end"]);
    }

    renderer->SetStyle(styleConfig);
}
```

```java
// Protocol.java 新增方法
public class Protocol {

    // 显示字幕
    public static Envelope showSubtitle(String text, String style, float x, float y, long durationMs) {
        JsonObject payload = new JsonObject();
        payload.addProperty("text", text);
        payload.addProperty("style", style);

        JsonObject position = new JsonObject();
        position.addProperty("x", x);
        position.addProperty("y", y);
        payload.add("position", position);

        payload.addProperty("duration", durationMs);

        return createCommand("show_subtitle", payload);
    }

    // 更新字幕
    public static Envelope updateSubtitle(String text) {
        JsonObject payload = new JsonObject();
        payload.addProperty("text", text);
        return createCommand("update_subtitle", payload);
    }

    // 隐藏字幕
    public static Envelope hideSubtitle() {
        return createCommand("hide_subtitle", new JsonObject());
    }
}
```

### 10.3 缓存优化

```cpp
// 缓存字形纹理
class GlyphCache {
private:
    std::unordered_map<uint32_t, texture_glyph_t*> _cache;

public:
    texture_glyph_t* GetGlyph(uint32_t charcode) {
        auto it = _cache.find(charcode);
        if (it != _cache.end()) {
            return it->second;
        }

        // 生成并缓存
        auto* glyph = texture_font_get_glyph(_font, charcode);
        _cache[charcode] = glyph;
        return glyph;
    }
};
```

## 11. 风险与挑战

| 风险 | 影响 | 缓解措施 |
|--------|--------|----------|
| 中/日文字符渲染质量 | 可读性差 | 使用高质量字体<br>调整hinting参数 |
| 内存占用过高 | 性能下降 | 限制纹理图集大小<br>实现LRU缓存 |
| Shader兼容性 | 渲染失败 | 使用GLSL 330核心<br>提供fallback |
| 网络延迟 | 字幕不同步 | 在Java层添加偏移调整<br>支持手动同步 |
