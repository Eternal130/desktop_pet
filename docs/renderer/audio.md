# 音频播放架构「Phase 3」

> **Phase 3 实现**：音频模块在控制面板（Phase 2）之后开发。音频文件与模型文件**分离管理**，支持跨模型复用，降低存储占用。
> 渲染引擎模块概览参见 [渲染引擎设计](./README.md)，整体架构参见 [架构总览](../README.md)。

---

## 一、音频管理设计

### 核心设计决策：音频与模型分离

传统方案将音频文件放在模型目录下（如 `models/Haru/sounds/`），导致：
- 相同音频在多个模型间重复存储，浪费磁盘空间
- 用户无法灵活组合不同模型与音频

本项目采用**音频独立管理**方案：

| 维度 | 传统方案（模型绑定） | 本项目方案（独立管理） |
| :--- | :--- | :--- |
| 存储位置 | 音频嵌入模型目录 | 音频存放在独立目录（`audio/`） |
| 存储占用 | 多模型共用音频时重复存储 | 同一音频文件仅存储一份 |
| 复用性 | 音频绑定单一模型 | 多个模型可引用同一音频文件 |
| 管理方式 | 由模型文件隐式关联 | 由控制面板通过映射配置显式管理 |
| 灵活性 | 用户无法自定义音频组合 | 用户可自由配置模型-动作-音频映射 |

### 音频类型

| 类型 | 说明 | 同步需求 | 管理方式 |
| :--- | :--- | :--- | :--- |
| **动作关联音频** | 与动作绑定的音效（如说话、点击反馈） | 高，需要与口型/表情精确同步 | 控制面板配置映射，渲染器按映射加载播放 |
| **独立音频** | 背景音乐、环境音效，与模型无直接关联 | 低，可独立播放 | 控制面板直接下发播放指令 |

## 二、职责分工

| 职责 | 控制面板 (Java) | 渲染器 (C++) |
| :--- | :--- | :--- |
| 音频文件导入/删除 | ✓ | ✗ |
| 音频映射配置（模型+动作 → 音频文件） | ✓ | ✗ |
| 音频映射下发 | ✓（通过 `set_audio_mapping` 指令） | ✓（接收并缓存映射） |
| 音频文件加载与解码 | ✗ | ✓ |
| 音画同步播放 | ✗ | ✓（精确同步，无网络延迟） |
| 音量/静音控制 | ✓（UI 操作 → 下发指令） | ✓（响应指令） |

**音频由渲染器播放**的理由：

| 考量因素 | 渲染器播放 | 控制面板播放 |
| :--- | :--- | :--- |
| 音画同步 | ✓ 精确同步，无网络延迟 | ✗ 需要额外同步机制 |
| 动作触发 | ✓ 与动作状态机天然耦合 | ✗ 需额外传递时间戳 |
| 实现复杂度 | ✓ 直接调用音频 API | ✗ 同步逻辑复杂 |
| 音量控制 | ✓ 接收指令即可 | ✓ 天然支持 |

## 三、音频模块架构

```plain
┌─────────────────────────────────────────────────────────────┐
│                    控制面板 (Java)                           │
│  ┌───────────────────────────────────────────────────────┐  │
│  │  音频管理 UI                                          │  │
│  │  - 音频文件导入/删除（FileChooser）                   │  │
│  │  - 音频映射配置（模型+动作组 → 音频文件路径）         │  │
│  │  - 音量滑块 / 静音开关                                │  │
│  └───────────────────────────────────────────────────────┘  │
└──────────────────────────┬──────────────────────────────────┘
                           │ set_audio_mapping / set_volume /
                           │ play_audio 指令
                           ▼
┌─────────────────────────────────────────────────────────────┐
│                 渲染引擎音频播放器 (C++)                     │
│  ┌───────────────────────────────────────────────────────┐  │
│  │  音频映射缓存                                         │  │
│  │  - 接收控制面板下发的映射配置                         │  │
│  │  - 动作触发时查找映射，定位音频文件路径               │  │
│  └───────────────────────────────────────────────────────┘  │
│  ┌───────────────────────────────────────────────────────┐  │
│  │  音频资源管理                                         │  │
│  │  - 从独立目录（audio/）加载音频文件                   │  │
│  │  - 缓存音频数据（LRU 策略）                          │  │
│  │  - 格式支持：WAV 原生，MP3/OGG 可选（dr_libs）       │  │
│  └───────────────────────────────────────────────────────┘  │
│  ┌───────────────────────────────────────────────────────┐  │
│  │  播放控制                                             │  │
│  │  - 动作触发 → 查映射 → 自动播放关联音频              │  │
│  │  - 音画同步（时间戳对齐）                             │  │
│  │  - 多音轨混合                                         │  │
│  └───────────────────────────────────────────────────────┘  │
│  ┌───────────────────────────────────────────────────────┐  │
│  │  音量管理                                             │  │
│  │  - 全局音量 / 音效音量（独立） / 静音状态             │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```
