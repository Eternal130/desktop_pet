Task 8: Shutdown Handler Evidence
==================================

The shutdown handler is registered in CommandHandlers.cpp:

  handler.registerCommand("shutdown", [delegate](const Envelope& cmd, auto sendResponse) {
      sendResponse(createResponse(cmd.id, "shutdown", true));
      glfwSetWindowShouldClose(delegate->GetWindow(), GLFW_TRUE);
  });

Behavior:
1. Sends a success response: { type: "response", action: "shutdown", success: true }
2. Calls glfwSetWindowShouldClose() which causes the main loop to exit on next iteration
3. The main loop in LAppDelegate::Run() checks glfwWindowShouldClose() each frame

The handler uses delegate->GetWindow() which returns the GLFWwindow* stored in LAppDelegate.

Build verification:
  cmake --build renderer/build exits 0
  All 18 unit tests pass

Note: Runtime verification of shutdown requires a display server (GLFW/OpenGL),
which is not available in this CI/container environment.
